T7 Bridge installer

Puts the T7 Bridge firmware on an ESP32-S3 board (16 MB flash) straight from this page.

  1. Use Chrome or Edge on a computer. Safari, Firefox and phones can't talk to USB devices.
  2. Plug the board in by its port labelled USB.
  3. Click Install, pick the board from the list, and allow erasing it.
  4. When it says it's done, tap the board's RST button.
This browser can't flash boards. Open this page in Chrome or Edge on a computer. This page must be opened over https.

Board not in the list, or the install fails? Hold BOOT, tap RST, let go of BOOT, then click Install again. New boards often need this once.
